# AESCON Maintenance App (F-MT-68-rev2)
ระบบตรวจสอบและบันทึกการซ่อมบำรุงเครื่องมือ/เครื่องจักรประจำปี 2026

## 📌 ข้อมูลระบบ
* **ที่ตั้งโฟลเดอร์:** `D:\AESCON Maintenance\Maintenance AES\แอปตรวจสอบเครื่องมือภายในบริษัท`
* **ข้อมูลอ้างอิง:** ชีต `F68 V.2` จากไฟล์ `F-MT-68-rev2-แผนการบำรุงรักษาเครื่องจักรประจำปี 2026.xlsx`
* **จำนวนเครื่องมือทั้งหมด:** 4,433 รายการ (ครอบคลุมกว่า 270 หมวดหมู่ เช่น `AES-A01`, `AES-B01` ฯลฯ)
* **รอบแผนงาน PM:** 8,788 รอบตลอด 48 สัปดาห์ (12 เดือน) ในปี 2026

## 🚀 วิธีเปิดใช้งานโปรแกรม (เปิดใช้งานง่ายมาก)

1. เข้าไปที่โฟลเดอร์ `D:\AESCON Maintenance\Maintenance AES\แอปตรวจสอบเครื่องมือภายในบริษัท`
2. ดับเบิลคลิกที่ไฟล์ **`start_app.bat`**
3. โปรแกรมจะเริ่มต้นระบบและเปิดหน้าเว็บเบราว์เซอร์ **`http://localhost:8000`** ให้โดยอัตโนมัติ

## 💻 ฟังก์ชันการใช้งานหลัก

1. **🔍 ค้นหาเครื่องมือ (Tool Registry):**
   - พิมพ์รหัสเครื่องจักร (เช่น `AES-A01-0001`) หรือชื่อเครื่องมือ (เช่น กรรไกร, สว่าน, หินเจียร) ค้นหาได้แบบทันที ไม่ต้องสแกน
   - กรองตามหมวดหมู่ หรือกรองตามสถานะ (พร้อมใช้ / รอซ่อม / ปลดระวาง)
   - กดปุ่ม **[บันทึกซ่อม]** เพื่อลงบันทึกได้ทันที
   - กดปุ่ม **[👁️ ดูแผนและประวัติ]** เพื่อเปิดดูตาราง 48 สัปดาห์ (Target P vs A) และประวัติย้อนหลังทั้งหมดของเครื่องมือนั้น

2. **📅 ตารางแผน PM ประจำสัปดาห์ (Weekly PM Due):**
   - เลือกเดือน และสัปดาห์ (Week 1 - 4) เพื่อดูว่ามีเครื่องมือใดถึงกำหนดตรวจตามแผน (Target P)
   - กรองดูเฉพาะรายการที่ "ยังไม่ได้ตรวจ" เพื่อติดตามงานค้าง
   - กดปุ่ม **[บันทึกผล PM]** เพื่อยืนยันการตรวจและลงผลจริง (Actual A)

3. **📝 ฟอร์มบันทึกการซ่อมบำรุง (Maintenance Form):**
   - รองรับประเภทงาน: PM ตามแผนประจำปี, แจ้งซ่อมฉุกเฉิน/ชำรุด (Breakdown), เปลี่ยนอะไหล่, ตรวจเช็คสภาพ
   - ระบุผู้ตรวจ, วันที่, รายละเอียดงาน, อะไหล่ที่เปลี่ยน, ค่าใช้จ่าย, ผลการตรวจ
   - เลือกว่าจะอัปเดตผลงานจริง (Actual A) ในตารางแผนประจำปีด้วยหรือไม่

4. **📜 ประวัติการซ่อมบำรุง (History Logs):**
   - ดูรายการประวัติการซ่อมทั้งหมดในระบบ
   - ค้นหาและกรองตามช่วงเวลา หรือผู้ตรวจ
   - มีปุ่ม **Export Excel/CSV** เพื่อนำข้อมูลออกไปใช้งานต่อในโปรแกรม Excel ได้ทันที

5. **📊 แดชบอร์ดสรุปผล (Executive Dashboard):**
   - ดูสถิติรวม % ความสำเร็จของแผนงาน PM ประจำปี
   - ดูสถิติจำนวนเครื่องมือแยกตามหมวดหมู่
